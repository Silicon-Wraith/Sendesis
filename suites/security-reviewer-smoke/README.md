# Security Reviewer smoke suite

Ten small planted cases (6 vulnerable, 4 clean) that prove the qualify pipeline end to end. Generated by `scripts/make_smoke_suite.py`, which computes each label's line from the planted line itself.

It is far below the role's `min_cases`, so any receipt from it is UNKNOWN by design. It says the plumbing works, not that a profile is qualified.

```bash
.venv/bin/sendesis qualify security-reviewer claude-opus --suite suites/security-reviewer-smoke
```

Cases are named `smoke-NN` so the id reveals nothing, and case ids never reach the prompt.
