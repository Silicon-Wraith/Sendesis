# M3.2 Router and Failover Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A router that picks only acceptable profiles under the family rules, a failover loop that reruns a failed seat on the next profile or refuses naming what is missing, and a `sendesis stage` command that runs one reviewer stage through them.

**Architecture:**
- `receipts.profile_status` gives the current status of one profile's receipt for one role.
- `router.py` is pure functions that turn roles, profiles and receipt statuses into candidates and an assignment, or a refusal.
- `gitstate.py` holds the git checks and resets.
- `failover.py` runs one seat slot until it succeeds, refuses or stops.
- `stage.py` runs a stage's slots in order and writes `.sendesis/runs/<run-id>/stage.json`.
- `cli.py` gains `stage`.

**Tech Stack:** Python 3.11, Agno 3.0.11, agno-cli-models v0.1.2, jsonschema, PyYAML, pytest, git.

**Spec:** `docs/specs/2026-10-02-sendesis-m3.2-router-design.md`. Its parent is `docs/specs/2026-10-01-sendesis-m3-design.md`, section 5. Recorded decisions:
- `m3-2-router-library-and-stage-command`
- `failover-in-sendesis-not-agno`
- `assignment-first-fit-with-backtracking`
- `failover-exclusion-scope`
- `reviewer-tree-change-stops-stage`
- `m3-2-exit-by-cli-shim`

## Global Constraints

Routing:
- The router MUST be the only code that chooses a profile for a seat.
- A profile MUST NOT be assigned to a seat of a role with a suite unless its receipt's effective status is QUALIFIED.
- A provisional assignment MUST record a warning.
- `distinct_families` MUST hold across a stage's seats of a role, at first assignment and after every failover.
- When no assignment exists, the stage MUST refuse before any further model call. The refusal MUST name:
  - the role;
  - the families needed;
  - the families acceptable;
  - every rejected profile with its reason.

Failover:
- A rate-limited profile MUST NOT be assigned again in the same run.
- A profile that stalled, timed out, errored or stayed invalid MUST NOT be assigned again to the same seat.
- A failed-over seat MUST rerun from its original input.
- A worker seat MUST first be reset to its starting commit, with only the untracked files it created removed.
- Only INVALID gets a same-profile retry (one). In runs, STALL gets none.

Tree and stopping:
- A stage MUST NOT start on a dirty tree. Sendesis MUST NOT commit or stash the operator's changes.
- A reviewer seat that changes the tree MUST stop the stage, and MUST NOT be failed over.
- An untyped exception MUST stop the stage, and MUST NOT be failed over.

Blinding and retries:
- No seat input may contain a profile name or a label-to-profile mapping.
- Agno's own retries MUST stay off for seats. `Agent.retries` stays at its default of 0; do not set it.

Repository rules:
- Every subprocess Sendesis spawns gets `stdin=subprocess.DEVNULL`.
- Unit tests use the scripted fake model or a scripted seat function. Real CLI calls go only in tests marked `@pytest.mark.integration`, which run only when the operator says go.
- In docs and user-facing text, do not use em dashes. Run every command from the worktree root with its own `.venv/bin/...`.

## Review Focus

1. **A role id in a workflow with no role file.** The stage must refuse, naming the role, not crash with a KeyError. Pinned in Task 5 by `test_missing_role_refuses_before_any_call`.
2. **A worker seat that created a nested untracked file before failing.** The reset must remove that file and must leave pre-existing untracked and ignored files alone. Pinned in Task 3 by `test_reset_removes_only_files_the_seat_created`.
3. **A rate limit on seat A followed by seat B.** B must never be offered the rate-limited profile, even though that profile never failed B. Pinned in Task 4 by `test_rate_limit_excludes_profile_from_later_seats`.
4. **A finished seat whose profile is later rate-limited by another seat.** The finished seat keeps its result, and its family still counts for `distinct_families`. Pinned in Task 4 by `test_finished_seat_keeps_profile_after_later_rate_limit`.
5. **A `--context` directory with nested files.** The message must carry each file under its path relative to the directory, and no profile name. Pinned in Task 6 by `test_cli_stage_reads_nested_context`.

```python
def _current_status(root: Path, receipt: dict[str, Any], role: Role, profile: Profile, now: datetime,
                    version_fn, versions: dict[str, str | None]) -> tuple[str, list[str]]:
    """Effective status of one single-profile receipt against the current role, profile, suite,
    CLI version and model configuration. Does not include the recorded status_reason."""
    cases = root / receipt["suite"]["path"] / "cases"
    current_suite = suite_sha256(cases) if cases.is_dir() else None
    if profile.cli_binary and profile.cli_binary not in versions:
        versions[profile.cli_binary] = version_fn(profile.cli_binary)
    try:
        fingerprint = current_fingerprint(profile, role)
    except Exception as exc:  # SandboxUnavailable, a missing binary: the receipt cannot hold
        return "UNKNOWN", [f"seat cannot be built: {exc}"]
    status, reasons = effective_status(
        receipt,
        role=role,
        profile=profile,
        suite_sha256=current_suite,
        cli_version=versions.get(profile.cli_binary) if profile.cli_binary else None,
        config_fingerprint=fingerprint,
        now=now,
    )
    if current_suite is None:
        reasons = reasons + [f"suite {receipt['suite']['path']} not found"]
        status = "UNKNOWN"
    return status, reasons


def profile_status(root: Path, role: Role, profile: Profile, now: datetime, *,
                   version_fn=None, versions: dict[str, str | None] | None = None) -> tuple[str, list[str]]:
    """Status the router may rely on for this role and profile: ("NONE", []) without a receipt,
    else the newest receipt's effective status, with drift reasons and then its recorded reason."""
    folder = root / "receipts" / role.id / profile.id
    files = sorted(folder.glob("*.json")) if folder.is_dir() else []
    if not files:
        return "NONE", []
    receipt = json.loads(files[-1].read_text(encoding="utf-8"))
    status, reasons = _current_status(root, receipt, role, profile, now, version_fn or installed_version,
                                      versions if versions is not None else {})
    if receipt.get("status_reason"):
        reasons = reasons + [receipt["status_reason"]]
    return status, reasons
```

```python
"""Helpers for router, failover and stage tests: fixture roles, workflows, a git root, scripted seats."""

from __future__ import annotations

import subprocess
from pathlib import Path

import yaml

from sendesis.seat import Outcome, SeatResult

GOOD = {"role_id": "x", "findings": [], "checks": [{"id": "injection", "outcome": "no_findings"}]}


def add_role(root: Path, role_id: str, *, order, kind: str = "reviewer", tools=("read", "search"), suite: bool = False) -> None:
    """A role copied from security-reviewer.yaml with a new id, failover order, kind and tools.
    Without `suite`, the qualification block is removed, so the role is provisional."""
    data = yaml.safe_load((root / "roles" / "security-reviewer.yaml").read_text())
    data.update(id=role_id, kind=kind, failover_order=list(order))
    data["tools"]["allowed"] = list(tools)
    if not suite:
        data.pop("qualification", None)
    (root / "roles" / f"{role_id}.yaml").write_text(yaml.safe_dump(data, sort_keys=False))


def write_workflow(root: Path, wid: str, seats: list[dict]) -> Path:
    (root / "workflows").mkdir(exist_ok=True)
    path = root / "workflows" / f"{wid}.yaml"
    data = {"id": wid, "version": "0.1.0", "description": "Fixture workflow for tests.",
            "stages": [{"id": "review", "seats": seats}]}
    path.write_text(yaml.safe_dump(data, sort_keys=False))
    return path


def git_init(root: Path) -> None:
    """Make `root` a git repository with one commit and `.sendesis/` ignored."""
    (root / ".gitignore").write_text(".sendesis/\n")
    for args in (["init", "-q"], ["add", "-A"],
                 ["-c", "user.name=t", "-c", "user.email=t@t", "commit", "-q", "-m", "fixture"]):
        subprocess.run(["git", *args], cwd=root, check=True, stdin=subprocess.DEVNULL, capture_output=True)


def result(outcome: Outcome, **kw) -> SeatResult:
    return SeatResult(outcome, reason=kw.pop("reason", outcome.value), **kw)


def ok() -> SeatResult:
    return SeatResult(Outcome.OK, output=dict(GOOD), input_tokens=10, output_tokens=5, wall_s=1.0)


def scripted(plan: dict[str, list]):
    """plan maps a profile id to the SeatResults (or callables taking cwd) it returns, in order."""
    calls = []

    def seat_fn(role, profile, message, cwd, timeout_s):
        calls.append((role.id, profile.id, message))
        item = plan[profile.id].pop(0)
        return item(cwd) if callable(item) else item

    seat_fn.calls = calls
    return seat_fn
```

```python
"""The router: the only code that chooses a profile for a seat.

Rules from docs/specs/2026-10-02-sendesis-m3.2-router-design.md, section 2. Pure
functions; no model calls. Seats of different roles are independent (one profile
may serve several roles), so each workflow seat is filled on its own.
"""

from __future__ import annotations

from dataclasses import dataclass
from pathlib import Path
from typing import Callable

from sendesis.model import REVIEWER_FORBIDDEN_TOOLS, Profile, Role, ValidationFailed, load_profile
from sendesis.workflow import Stage

ACCEPTABLE, PROVISIONAL, REJECTED = "acceptable", "provisional", "rejected"
PLACEHOLDER = "set-me"

StatusFn = Callable[[Role, Profile], tuple[str, list[str]]]


@dataclass(frozen=True)
class Candidate:
    profile_id: str
    verdict: str
    family: str | None = None
    reason: str = ""

    @property
    def usable(self) -> bool:
        return self.verdict in (ACCEPTABLE, PROVISIONAL)


@dataclass(frozen=True)
class Slot:
    label: str
    role_id: str
    seat_index: int


@dataclass(frozen=True)
class Assignment:
    profiles: dict[str, str]
    families: dict[str, str]
    warnings: tuple[str, ...]


@dataclass(frozen=True)
class Refusal:
    text: str


def sandbox_problem(role: Role) -> str | None:
    bad = [t for t in role.tools_allowed if t in REVIEWER_FORBIDDEN_TOOLS]
    if bad:
        return f"sandbox unavailable: {role.id} needs {', '.join(bad)}; sandboxed edit and shell seats arrive in M3.3"
    return None


def candidates(role: Role, root: Path, status_fn: StatusFn, *, excluded: dict[str, str] | None = None,
               sandbox: Callable[[Role], str | None] = sandbox_problem) -> list[Candidate]:
    excluded = excluded or {}
    out: list[Candidate] = []
    for pid in role.failover_order:
        try:
            profile = load_profile(root / "profiles" / f"{pid}.yaml", root)
        except (ValidationFailed, FileNotFoundError) as exc:
            out.append(Candidate(pid, REJECTED, None, f"profile file missing or invalid: {exc}"))
            continue
        family = profile.family
        if not profile.enabled:
            out.append(Candidate(pid, REJECTED, family, "disabled"))
            continue
        if pid in excluded:
            out.append(Candidate(pid, REJECTED, family, excluded[pid]))
            continue
        problem = sandbox(role)
        if problem:
            out.append(Candidate(pid, REJECTED, family, problem))
            continue
        if role.provisional:
            if family == PLACEHOLDER:
                out.append(Candidate(pid, REJECTED, family, f"family is the placeholder '{PLACEHOLDER}'"))
            else:
                out.append(Candidate(pid, PROVISIONAL, family))
            continue
        status, reasons = status_fn(role, profile)
        if status == "QUALIFIED":
            out.append(Candidate(pid, ACCEPTABLE, family))
        elif status == "NONE":
            out.append(Candidate(pid, REJECTED, family, "no receipt"))
        else:
            out.append(Candidate(pid, REJECTED, family, f"receipt {status}" + (f": {'; '.join(reasons)}" if reasons else "")))
    return out


def slots(stage: Stage) -> list[Slot]:
    out: list[Slot] = []
    for index, seat in enumerate(stage.seats):
        for _ in range(seat.count):
            out.append(Slot(chr(ord("A") + len(out)), seat.role, index))
    return out


def _options(slot: Slot, cands: dict[str, list[Candidate]], fixed: dict[str, str]) -> list[Candidate]:
    if slot.label in fixed:  # a finished seat keeps its profile, whatever happened since
        return [c for c in cands[slot.label] if c.profile_id == fixed[slot.label]]
    return [c for c in cands[slot.label] if c.usable]


def _fill(seat_slots: list[Slot], cands, fixed, need: int) -> list[Candidate] | None:
    def walk(i: int, picked: list[Candidate]) -> list[Candidate] | None:
        if i == len(seat_slots):
            return picked if len({c.family for c in picked}) >= need else None
        for c in _options(seat_slots[i], cands, fixed):
            found = walk(i + 1, picked + [c])
            if found is not None:
                return found
        return None

    return walk(0, [])


def _refusal(stage: Stage, role_id: str, need: int, seat_slots: list[Slot], cands, fixed) -> Refusal:
    acceptable: dict[str, list[str]] = {}
    for s in seat_slots:
        for c in _options(s, cands, fixed):
            names = acceptable.setdefault(c.family, [])
            if c.profile_id not in names:
                names.append(c.profile_id)
    families = ", ".join(f"{fam}: {', '.join(names)}" for fam, names in acceptable.items()) or "none"
    word = "family" if need == 1 else "families"
    lines = [f"refused: stage {stage.id}: {role_id} needs {need} {word}, {len(acceptable)} acceptable ({families})"]
    seen: set[tuple[str, str]] = set()
    for s in seat_slots:
        for c in cands[s.label]:
            if not c.usable and (c.profile_id, c.reason) not in seen:
                seen.add((c.profile_id, c.reason))
                lines.append(f"  rejected: {c.profile_id}: {c.reason}")
    return Refusal("\n".join(lines))


def assign(stage: Stage, slot_list: list[Slot], cands: dict[str, list[Candidate]], fixed: dict[str, str]) -> Assignment | Refusal:
    profiles: dict[str, str] = {}
    families: dict[str, str] = {}
    warnings: list[str] = []
    for index, seat in enumerate(stage.seats):
        seat_slots = [s for s in slot_list if s.seat_index == index]
        chosen = _fill(seat_slots, cands, fixed, seat.distinct_families)
        if chosen is None:
            return _refusal(stage, seat.role, seat.distinct_families, seat_slots, cands, fixed)
        for s, c in zip(seat_slots, chosen):
            profiles[s.label], families[s.label] = c.profile_id, c.family
            if c.verdict == PROVISIONAL:
                w = f"{seat.role} is provisional: no suite, profile {c.profile_id} not qualified"
                if w not in warnings:
                    warnings.append(w)
    return Assignment(profiles, families, tuple(warnings))


def route(stage: Stage, roles: dict[str, Role], root: Path, status_fn: StatusFn, *, fixed: dict[str, str],
          run_excluded: dict[str, str], slot_excluded: dict[str, dict[str, str]],
          sandbox: Callable[[Role], str | None] = sandbox_problem) -> Assignment | Refusal:
    slot_list = slots(stage)
    cands = {
        s.label: candidates(roles[s.role_id], root, status_fn,
                            excluded={**run_excluded, **slot_excluded.get(s.label, {})}, sandbox=sandbox)
        for s in slot_list
    }
    return assign(stage, slot_list, cands, fixed)
```

```python
"""Git checks and resets for stage seats (M3.2 spec, section 3).

A stage starts only on a clean tree. A reviewer seat must leave the tree as it found
it. A worker seat that fails over is reset to its starting commit, and only the
untracked files it created are removed; ignored files are never touched.
"""

from __future__ import annotations

import subprocess
from dataclasses import dataclass
from pathlib import Path


class GitError(Exception):
    pass


@dataclass(frozen=True)
class Snapshot:
    head: str
    untracked: frozenset[str]
    status: str


def _git(cwd: Path, *args: str) -> str:
    r = subprocess.run(["git", *args], cwd=cwd, stdin=subprocess.DEVNULL, capture_output=True, text=True)
    if r.returncode != 0:
        raise GitError(f"git {' '.join(args)} failed in {cwd}: {r.stderr.strip()}")
    return r.stdout


def is_clean(cwd: Path) -> bool:
    return _git(cwd, "status", "--porcelain") == ""


def snapshot(cwd: Path) -> Snapshot:
    head = _git(cwd, "rev-parse", "HEAD").strip()
    untracked = frozenset(p for p in _git(cwd, "ls-files", "--others", "--exclude-standard", "-z").split("\0") if p)
    return Snapshot(head, untracked, _git(cwd, "status", "--porcelain"))


def unchanged(cwd: Path, snap: Snapshot) -> bool:
    return snapshot(cwd) == snap


def reset_to(cwd: Path, snap: Snapshot) -> None:
    _git(cwd, "reset", "-q", "--hard", snap.head)
    for rel in sorted(snapshot(cwd).untracked - snap.untracked):
        path = Path(cwd) / rel
        if path.is_file() or path.is_symlink():
            path.unlink()
```

```python
"""Running one seat slot until it succeeds, refuses or stops (M3.2 spec, section 3).

INVALID gets one retry on the same profile; RATE_LIMIT excludes the profile for the
rest of the run; any other failure excludes it for this seat only. Before each
attempt the whole stage is routed again, so the family rule holds after every
failover. An untyped exception, or a reviewer that changed the tree, stops the stage
and is never failed over.
"""

from __future__ import annotations

from dataclasses import dataclass, field
from pathlib import Path
from typing import Any, Callable

from sendesis.gitstate import reset_to, snapshot, unchanged
from sendesis.model import Profile, Role, load_profile
from sendesis.router import Refusal, Slot, StatusFn, route, sandbox_problem
from sendesis.seat import Outcome, SeatResult
from sendesis.workflow import Stage

SeatFn = Callable[[Role, Profile, str, Path, float], SeatResult]


class StageStopped(Exception):
    pass


@dataclass
class Attempt:
    label: str
    role: str
    profile: str
    family: str
    outcome: str
    reason: str
    stall: dict[str, Any] | None
    wall_s: float
    input_tokens: int
    output_tokens: int


@dataclass
class RunState:
    fixed: dict[str, str] = field(default_factory=dict)
    run_excluded: dict[str, str] = field(default_factory=dict)
    slot_excluded: dict[str, dict[str, str]] = field(default_factory=dict)
    attempts: list[Attempt] = field(default_factory=list)
    warnings: list[str] = field(default_factory=list)


def timeout_for(role: Role, profile: Profile) -> float:
    return min(t for t in (profile.timeout_s, role.per_call_timeout_s) if t)


def _call(slot: Slot, role: Role, profile: Profile, family: str, message: str, cwd: Path,
          state: RunState, seat_fn: SeatFn) -> SeatResult:
    before = snapshot(cwd)
    try:
        res = seat_fn(role, profile, message, cwd, timeout_for(role, profile))
    except Exception as exc:
        raise StageStopped(f"seat {slot.label} ({role.id}): untyped exception {type(exc).__name__}: {exc}") from exc
    state.attempts.append(Attempt(slot.label, role.id, profile.id, family, res.outcome.value, res.reason,
                                  res.stall, res.wall_s, res.input_tokens, res.output_tokens))
    if role.kind == "reviewer" and not unchanged(cwd, before):
        raise StageStopped(f"reviewer seat {slot.label} ({role.id}) changed the tree")
    return res


def run_slot(slot: Slot, stage: Stage, roles: dict[str, Role], state: RunState, *, root: Path, cwd: Path,
             messages: dict[str, str], status_fn: StatusFn, seat_fn: SeatFn,
             sandbox: Callable[[Role], str | None] = sandbox_problem) -> SeatResult | Refusal:
    role = roles[slot.role_id]
    while True:
        plan = route(stage, roles, root, status_fn, fixed=state.fixed, run_excluded=state.run_excluded,
                     slot_excluded=state.slot_excluded, sandbox=sandbox)
        if isinstance(plan, Refusal):
            return plan
        for w in plan.warnings:
            if w not in state.warnings:
                state.warnings.append(w)
        pid = plan.profiles[slot.label]
        profile = load_profile(root / "profiles" / f"{pid}.yaml", root)
        start = snapshot(cwd)
        res = _call(slot, role, profile, plan.families[slot.label], messages[role.id], cwd, state, seat_fn)
        if res.outcome is Outcome.INVALID:  # one retry on the same profile
            res = _call(slot, role, profile, plan.families[slot.label], messages[role.id], cwd, state, seat_fn)
        if res.outcome is Outcome.OK:
            state.fixed[slot.label] = pid
            return res
        if res.outcome is Outcome.RATE_LIMIT:
            state.run_excluded[pid] = "rate-limited earlier in this run"
        else:
            state.slot_excluded.setdefault(slot.label, {})[pid] = f"failed this seat ({res.outcome.value})"
        if role.kind != "reviewer":
            reset_to(cwd, start)
```

```python
"""`sendesis stage`: run one stage's seats through the router and failover (M3.2).

No evidence pack, adjudication or gate: those arrive with the M3.3 compiler, which
builds on run_stage. The record goes to .sendesis/runs/<run-id>/ (ignored by git).
"""

from __future__ import annotations

import hashlib
import json
from dataclasses import asdict, dataclass, field
from datetime import datetime, timezone
from pathlib import Path
from typing import Any, Callable

from sendesis.failover import Attempt, RunState, SeatFn, StageStopped, run_slot
from sendesis.gitstate import GitError, is_clean
from sendesis.model import Role, ValidationFailed, load_role
from sendesis.qualify import review_message
from sendesis.receipts import iso, profile_status
from sendesis.router import Refusal, StatusFn, route, sandbox_problem, slots
from sendesis.seat import run_role
from sendesis.workflow import load_workflow


class StageError(Exception):
    pass


@dataclass
class StageResult:
    run_id: str
    status: str
    refusal: str | None
    stop_reason: str | None
    initial_assignment: dict[str, str]
    attempts: list[Attempt]
    seats: dict[str, dict[str, Any]]
    warnings: list[str]
    record_path: Path


def default_seat_fn(root: Path) -> SeatFn:
    def seat_fn(role, profile, message, cwd, timeout_s):
        return run_role(role, profile, message, root=root, cwd=cwd, timeout_s=timeout_s)
    return seat_fn


def _cached_status(root: Path, now: datetime) -> StatusFn:
    versions: dict[str, str | None] = {}
    cache: dict[tuple[str, str], tuple[str, list[str]]] = {}

    def status_fn(role, profile):
        key = (role.id, profile.id)
        if key not in cache:
            cache[key] = profile_status(root, role, profile, now, versions=versions)
        return cache[key]
    return status_fn


def run_stage(root: Path, workflow_path: Path, stage_id: str, *, diff: str, context: dict[str, str] | None = None,
              cwd: Path | None = None, now: datetime | None = None, seat_fn: SeatFn | None = None,
              status_fn: StatusFn | None = None, runs_dir: Path | None = None,
              sandbox: Callable[[Role], str | None] = sandbox_problem) -> StageResult:
    now = now or datetime.now(timezone.utc)
    cwd = cwd or root
    context = context or {}
    try:
        wf = load_workflow(workflow_path, root)
    except (ValidationFailed, FileNotFoundError) as exc:
        raise StageError(str(exc)) from exc
    stage = next((s for s in wf.stages if s.id == stage_id), None)
    if stage is None:
        raise StageError(f"workflow {wf.id} has no stage {stage_id}")
    run_id = now.strftime("%Y%m%dT%H%M%SZ")
    run_dir = (runs_dir or root / ".sendesis" / "runs") / run_id
    state = RunState()
    initial: dict[str, str] = {}
    finished: dict[str, tuple[str, str, Any]] = {}

    def finish(status: str, *, refusal: str | None = None, stop_reason: str | None = None) -> StageResult:
        run_dir.mkdir(parents=True, exist_ok=True)
        seats = {}
        for label, (role_id, pid, output) in finished.items():
            (run_dir / f"seat-{label}.json").write_text(json.dumps(output, indent=2) + "\n", encoding="utf-8")
            seats[label] = {"role": role_id, "profile": pid, "outcome": "ok", "output": f"seat-{label}.json"}
        record = {
            "run_id": run_id,
            "workflow": {"id": wf.id, "sha256": wf.sha256},
            "stage": stage.id,
            "started_at": iso(now),
            "finished_at": iso(datetime.now(timezone.utc)),
            "input_sha256": hashlib.sha256(json.dumps({"diff": diff, "context": context}, sort_keys=True).encode()).hexdigest(),
            "status": status,
            "warnings": state.warnings,
            "initial_assignment": initial,
            "attempts": [asdict(a) for a in state.attempts],
            "seats": seats,
        }
        if refusal is not None:
            record["refusal"] = refusal
        if stop_reason is not None:
            record["stop_reason"] = stop_reason
        path = run_dir / "stage.json"
        path.write_text(json.dumps(record, indent=2) + "\n", encoding="utf-8")
        return StageResult(run_id, status, refusal, stop_reason, initial, state.attempts, seats, state.warnings, path)

    roles: dict[str, Role] = {}
    for seat in stage.seats:
        try:
            roles[seat.role] = load_role(root / "roles" / f"{seat.role}.yaml", root)
        except (ValidationFailed, FileNotFoundError):
            return finish("refused", refusal=f"refused: stage {stage.id}: role {seat.role} not found")
    try:
        clean = is_clean(cwd)
    except GitError as exc:
        return finish("refused", refusal=f"refused: {exc}")
    if not clean:
        return finish("refused", refusal="refused: dirty tree: commit or stash first")

    status_fn = status_fn or _cached_status(root, now)
    seat_fn = seat_fn or default_seat_fn(root)
    plan = route(stage, roles, root, status_fn, fixed={}, run_excluded={}, slot_excluded={}, sandbox=sandbox)
    if isinstance(plan, Refusal):
        return finish("refused", refusal=plan.text)
    initial.update(plan.profiles)
    state.warnings.extend(plan.warnings)
    messages = {rid: review_message(rid, diff, context) for rid in roles}
    try:
        for slot in slots(stage):
            res = run_slot(slot, stage, roles, state, root=root, cwd=cwd, messages=messages,
                           status_fn=status_fn, seat_fn=seat_fn, sandbox=sandbox)
            if isinstance(res, Refusal):
                return finish("refused", refusal=res.text)
            finished[slot.label] = (slot.role_id, state.fixed[slot.label], res.output)
    except StageStopped as exc:
        return finish("stopped", stop_reason=str(exc))
    return finish("completed")
```

```python
def cmd_stage(args: argparse.Namespace) -> int:
    from sendesis.stage import StageError, run_stage

    root = Path(args.root)
    wf = Path(args.workflow) if args.workflow.endswith((".yaml", ".yml")) else root / "workflows" / f"{args.workflow}.yaml"
    diff = Path(args.diff).read_text(encoding="utf-8")
    context: dict[str, str] = {}
    if args.context:
        base = Path(args.context)
        context = {p.relative_to(base).as_posix(): p.read_text(encoding="utf-8")
                   for p in sorted(base.rglob("*")) if p.is_file()}
    try:
        r = run_stage(root, wf, args.stage, diff=diff, context=context)
    except StageError as exc:
        print(f"FAIL {exc}")
        return 2
    print(f"{r.status.upper()}  stage {args.stage} of {wf.stem}  (run {r.run_id})")
    for w in r.warnings:
        print(f"  warning: {w}")
    for a in r.attempts:
        print(f"  seat {a.label}: {a.outcome} {a.wall_s:.1f}s" + (f"  {a.reason[:160]}" if a.reason and a.outcome != "ok" else ""))
    if r.refusal:
        print("  " + r.refusal.replace("\n", "\n  "))
    if r.stop_reason:
        print(f"  stopped: {r.stop_reason}")
    print("  mapping:")
    for a in r.attempts:
        print(f"    {a.label} {a.profile} {a.outcome}")
    print(f"  record: {r.record_path}")
    return 0 if r.status == "completed" else 1
```
